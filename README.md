# Vrinda Store Analytics Dashboard

An e-commerce data analysis project using Microsoft Excel to explore store sales performance and present business data through visualizations and dashboards.

## Project Overview

This project focuses on analyzing Vrinda Store's sales data using Microsoft Excel. The goal is to organize business data, identify useful trends, and present findings through a dashboard that makes performance easier to understand.

## Project Objectives

* Analyze store sales data.
* Understand sales performance across different categories.
* Explore customer purchasing patterns.
* Present important metrics using charts and visualizations.
* Support data-driven business decisions.

## Tools and Technologies

* Microsoft Excel
* Power Query
* PivotTables
* Excel Formulas and Functions
* Data Cleaning
* Data Analysis
* Data Visualization
